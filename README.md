## 買完怎麼用：只登 App Store，別碰 iCloud

成品號的設計用途是登入 App Store 下載 App，不是拿來當主力 Apple ID。iPhone 上打開 App Store，點右上角頭像，下拉到最底按「登出」，再在頂部輸入帳號密碼登入。全程不要到「設定」裡登入 iCloud：iCloud 會觸發裝置綁定、「尋找我的 iPhone」和照片同步，海外號登 iCloud 被風控盯上的機率高得多。確實需要登 iCloud 的話，登入後立刻關掉「尋找」。

下載完要用的 App，切回自己的國區帳號再開 App。已經下載的 App 不會因為切號被刪掉。

改密碼之前有一件事要先做：到 appleid.apple.com 把帳號綁成自己的手機號碼，再改密碼。順序反過來，原綁定的虛擬裝置收不到驗證碼，後續登入會卡住。拿到號的當天就把密碼、密保問題、能綁的信箱和手機全部換成自己的。平台出貨後會刪檔，帳號被盜了找不回來。

驗號清單，7 項逐條走一遍：

1. 能否登入 appleid.apple.com 看到完整帳戶資訊
2. 能否修改密碼，且新密碼生效
3. 能否加入自己的雙重認證手機號碼，並刪掉賣家的
4. 登入裝置列表裡有沒有陌生裝置，全部移除
5. 購買記錄裡有沒有異常消費或未授權訂閱
6. 能否修改帳單地址和安全問題答案
7. 開啟「尋找我的 iPhone」，確認裝置控制權在自己手裡

任何一項失敗，當天就申請換號或棄號。有隱患的號比沒有更麻煩，之後儲進去的禮品卡餘額、訂閱服務、綁定的付款方式，封號後一起清零。

## 這幾個操作最容易把號弄封

- 登 iCloud。成品號只在 App Store 用，登 iCloud 等於把裝置交給一個來路不正的帳號託管。
- 跨區 IP 混用。用國區 IP 登美區號、再切回美區 IP，容易觸發驗證；固定用美區節點登入會穩一些。
- 餘額沒清空就切區。餘額不為 0 時切區按鈕是灰的，強制切區會觸發帳號限制，已購記錄清零，要恢復得找蘋果客服，等 5–7 個工作日。
- 買 10 元以下的低價號。這個價位多是機器批量註冊，IP 段被標記，存活時間很短，反覆買的錢比一次買正規號還多。
- 新號首週直接大額訂閱。有整理文章建議先花幾天登入 App Store 瀏覽、下載一兩個免費 App，之後再開付費服務，比較不容易被風控攔下。
- 不開雙重認證。沒開 2FA 的號被盜風險明顯更高，拿到號當天就開。

## 常見問題

**買的號能用多久？**
海外帳號沒有確定的使用期限，平台也不保證永久有效。蘋果因政策或風控收回屬於官方行為，平台不承擔責任。能做的部分是保持活躍、定期改密、固定節點。

**被盜了能找回嗎？**
平台出貨後刪檔，帳號被盜平台找不回。拿到號當天改密、綁自己的信箱和手機、開雙重認證，這幾步不做等於把號半掛在別人手裡。

**多久出貨？**
自動出貨，付款後幾分鐘就能在訂單中心提取，最長不超過 24 小時。

**能退款嗎？**
虛擬商品一經出貨不支持退款，除非帳密本身有問題（登不進去、資訊錯誤），這種在 3 天售後期內免費更換。

**能批量買嗎？**
可以。10 個起批有折扣，需要大量採購的直接聯絡線上客服談批發價。

**買來的號能登 iCloud 嗎？**
不建議。成品號的用途是登 App Store 下載 App，登 iCloud 風險高。確實要登，登入後立刻關掉「尋找我的 iPhone」，用完盡快登出。
